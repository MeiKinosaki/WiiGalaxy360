# v2.34b — referência executável para PPC subfc

## Objetivo
Adicionar uma referência executável para validar a semântica de subfc enquanto o ponto de integração no interpretador do emulador é identificado.

## Semântica coberta
- Resultado de 32 bits: `RB - RA`.
- XER.CA fica definido quando a subtração unsigned não precisa de empréstimo (`RB >= RA`).
- XER.OV e XER.SO são preservados pela instrução básica sem OE.
- Truncamento dos operandos a 32 bits.

## Execução
```sh
python3 tests/ppc_subfc_reference.py
```

## Resultado atual
A referência foi executada localmente: 7 testes passaram. Estes testes validam apenas o modelo de referência em Python. **Não testam o interpretador PowerPC do WiiGalaxy360**, porque a integração com o núcleo C/C++ ainda não foi confirmada. Não são evidência de boot de jogos ou funcionamento em Xbox 360.
