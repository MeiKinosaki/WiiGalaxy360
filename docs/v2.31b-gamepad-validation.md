# v2.31b — Navegação experimental com Gamepad API

## Objetivo

Preparar suporte experimental a controles reconhecidos pela Gamepad API do navegador na biblioteca web. Esta etapa não implementa controle nativo no Xbox 360 e não integra o controle ao `default.xex`.

## Escopo

- Mostrar estado de conexão/desconexão.
- Permitir navegação da biblioteca por direcional/analógico quando o foco estiver na biblioteca.
- Usar o botão primário padrão para ativar o controle focado e o secundário para a ação de retorno definida pela interface.
- Manter teclado e mouse como alternativas.
- Não armazenar identificadores do controle, eixos ou pressionamentos no armazenamento local.

## Requisitos técnicos para a implementação

1. Usar um único ciclo de leitura, evitando múltiplas chamadas paralelas a `requestAnimationFrame`.
2. Parar o ciclo quando não houver controle conectado e reiniciá-lo após `gamepadconnected` ou interação permitida pelo navegador.
3. Extrair a navegação espacial para uma função compartilhada, em vez de criar eventos de teclado artificiais.
4. Respeitar foco, campos de texto, menus de seleção e itens filtrados/ocultos.
5. Tratar os índices dos botões como dependentes do mapeamento reportado pelo navegador.
6. Anunciar o estado do controle com `aria-live` sem inundar leitores de tela com atualizações contínuas.
7. Não afirmar suporte a controle físico no Xbox 360 sem uma implementação nativa e teste real.

## Testes manuais de aceitação

- [ ] A página funciona por mouse/teclado sem controle.
- [ ] A conexão de controle é anunciada.
- [ ] Direcional e analógico movem o foco apenas entre cartões visíveis.
- [ ] Um pressionamento do botão primário ativa o elemento focado uma única vez.
- [ ] O botão secundário executa a ação de retorno prevista sem abrir um jogo.
- [ ] Pesquisa e filtros não permitem focar cartões ocultos.
- [ ] É possível alternar entre biblioteca e configurações.
- [ ] Desconexão/reconexão não deixa ciclos de leitura duplicados.
- [ ] A página continua responsiva depois de vários minutos.
- [ ] Nenhum teste sugere que uma ROM foi carregada ou emulada.

## Critério de conclusão

A versão só pode ser marcada como validada depois de executar e registrar os testes. A conclusão desses testes valida somente o protótipo web. O núcleo de emulação Wii permanece incompleto e a execução em hardware Xbox 360 RGH não é comprovada.
