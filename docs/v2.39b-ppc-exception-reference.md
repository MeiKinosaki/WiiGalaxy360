# v2.39b — referência de classificação de falhas de memória

## Implementado
Adicionada `tests/ppc_exception_reference.py` com dez cenários para classificar metadados de acesso:
- acesso válido de dados e busca de instrução no modelo;
- desalinhamento de halfword/word;
- endereço negativo e acesso que ultrapassa o limite;
- largura de acesso não suportada;
- tipo de acesso desconhecido;
- preservação do metadado de escrita;
- acesso exatamente na fronteira válida.

## Executar
```sh
python3 tests/ppc_exception_reference.py
```

## Limitações
A classificação é um modelo de teste simplificado. Não implementa SRR0/SRR1, DAR/DSISR, vetores de exceção, regras específicas de cada instrução, nem o handler PowerPC real. Não está ligada ao barramento de memória do WiiGalaxy360 e não demonstra execução de jogos.
