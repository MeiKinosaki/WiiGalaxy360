# v2.36b — referência de comparações PowerPC

## Implementado
A suíte `tests/ppc_compare_reference.py` contém 12 testes para comparação signed e unsigned de registradores de 32 bits, incluindo valores com o bit mais alto definido, igualdade, truncamento para 32 bits e códigos LT/GT/EQ do campo CR.

## Execução
```sh
python3 tests/ppc_compare_reference.py
```

## Resultado
Os 12 testes da referência foram executados localmente e passaram.

## Limitação
A referência não está ligada ao interpretador PowerPC do WiiGalaxy360. O campo CR completo, a propagação de XER.SO e a implementação real das instruções compare ainda precisam ser integrados e testados no núcleo do emulador. Não há evidência aqui de build Xenon ou boot de jogos Wii.
