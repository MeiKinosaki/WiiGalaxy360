# v2.35b — referência aritmética PowerPC

## Conteúdo
Adiciona `tests/ppc_arithmetic_reference.py` com dez casos de referência para:
- `addc`: soma de 32 bits e carry-out unsigned.
- `subf`: ordem dos operandos e resultado modular.
- `subfe`: empréstimo de entrada a partir de XER.CA e carry resultante.
- Preservação dos bits XER.OV e XER.SO nos modelos cobertos.
- Truncamento de operandos a 32 bits.

## Como executar
```sh
python3 tests/ppc_arithmetic_reference.py
```

## Resultado e limites
Os dez cenários foram verificados localmente com uma checagem de referência. A suíte deve ser executada com Python no checkout antes do merge. Os helpers são oráculos auxiliares e **não estão ligados ao dispatcher da CPU do WiiGalaxy360**. Não provam que o núcleo em C/C++ implementa as instruções corretamente e não são testes de boot de Wii.

## Próximo marco técnico
Encontrar o dispatcher PowerPC real, ligar testes às rotinas do emulador e estabelecer build/teste repetível para Xenon.
