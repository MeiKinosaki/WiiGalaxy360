# v2.32b — Limites e validação defensiva de importação

## Alterações

- Recusa arquivos de catálogo JSON maiores que 5 MiB antes de interpretar o conteúdo.
- Recusa catálogos com mais de 10.000 entradas para limitar o trabalho da interface.
- Valida comprimento e caracteres de controle de IDs, nomes e caminhos de metadados.
- Recusa arquivos de capa acima de 2 MiB por arquivo.
- Atualiza a identificação do exportador JSON para v2.32b.

## Testes e limites

- A alteração foi gravada na branch `v2.32b-catalog-hardening`; testes automatizados, revisão em navegador e testes em hardware ainda não foram executados.
- Os limites reduzem entradas excessivas, mas não validam se ROMs existem, são seguras, legítimas ou compatíveis.
- Capas continuam armazenadas no `localStorage` como Data URLs e podem esgotar a quota do navegador.
- O protótipo web continua separado do `default.xex`; esta versão não adiciona emulação funcional de jogos Wii.
