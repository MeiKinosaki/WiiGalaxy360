# Código-fonte

Este diretório é reservado à implementação do emulador WiiGalaxy360.

## Estado atual

O repositório ainda não contém um núcleo completo de emulação Wii pronto para uso. Os diretórios abaixo documentam componentes planejados; não são implementações concluídas.

- `cpu/`: interpretador PowerPC/Broadway e estado dos registradores.
- `memory/`: mapa de memória, acessos e barramentos.
- `video/`: futura camada gráfica/Flipper.
- `audio/`: futura emulação de áudio.
- `ios/`: futuras interfaces e serviços IOS.

Cada componente deve ganhar código executável e testes antes de ser declarado funcional.
