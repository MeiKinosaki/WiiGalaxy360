Teclado: Tab para controles; nas capas, use ↑ ↓ ← → para percorrer os jogos, Home/End para início/fim e Enter para abrir detalhes. Controle web experimental: direcional/analógico navega; botão principal ativa o foco.

Controle web: aguardando detecção do navegador. Não representa suporte ao controle nativo do Xbox 360.
